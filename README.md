# 에어팟 배터리 (갤럭시용)

갤럭시(안드로이드) 폰에 에어팟을 연결/착용했을 때 왼쪽·오른쪽·케이스
배터리 잔량을 자동으로 표시해주는 앱입니다.

## 원리
안드로이드는 애플 기기가 아니어서 에어팟 배터리를 공식적으로 읽는
방법이 없습니다. 대신 에어팟은 케이스를 열거나 착용 중일 때 배터리
정보를 블루투스 저전력(BLE) 신호에 실어 주변에 방송합니다. 아이폰이
배터리 팝업을 띄울 때 읽는 바로 그 신호입니다. 이 앱은 그 신호를
읽어서 배터리 퍼센트로 보여줍니다. 비공식적으로 알려진 신호 포맷을
이용하는 것이라, 기기·펌웨어에 따라 표시가 약간 다를 수 있습니다.

이 저장소에는 소스 코드만 있고 완성된 apk 파일은 들어있지 않습니다.
아래 두 방법 중 하나로 직접 빌드해야 합니다.

## 방법 A. Android Studio로 빌드 (추천)
1. https://developer.android.com/studio 에서 Android Studio 설치
2. Android Studio 실행 → Open → 이 프로젝트 폴더(AirPodsBattery) 선택
3. 처음 열면 Gradle 동기화가 자동 진행됩니다(몇 분 소요, 인터넷 필요)
4. 상단 메뉴 Build → Build App Bundle(s) / APK(s) → Build APK(s)
5. 빌드 완료 알림의 "locate"를 눌러 apk 위치로 이동
   (보통 app/build/outputs/apk/debug/app-debug.apk)
6. apk 파일을 폰으로 옮겨서 설치

## 방법 B. GitHub Actions로 클라우드 빌드 (설치 없이)
1. github.com 에서 새 저장소 생성
2. 이 폴더의 파일 전체를 저장소에 업로드
3. 저장소의 "Actions" 탭으로 이동하면 자동으로 빌드 시작
4. 완료된 워크플로 화면 아래 "Artifacts"에서 app-debug-apk 다운로드
   (zip 파일이며, 안에 apk가 들어있습니다)
5. apk 파일을 폰으로 옮겨서 설치

## 폰에 설치하기
1. apk 파일을 폰으로 전송 (나에게 카톡 보내기, 이메일, USB 등)
2. 파일 탭 → "출처를 알 수 없는 앱" 설치 허용
3. 앱 실행 후 블루투스/알림 권한 모두 허용

## 계속 안정적으로 동작하게 하려면
- 설정 → 배터리 → 백그라운드 사용량 제한에서 이 앱을 제외 처리하면
  삼성 절전 기능 때문에 백그라운드에서 꺼지는 것을 막을 수 있습니다.
- 블루투스는 항상 켜져 있어야 합니다.

## 알려진 한계
- "내 에어팟"인지 구분하지 않으므로, 아주 가까이 있는 다른 사람의
  에어팟 신호를 순간적으로 잡을 수도 있습니다.
- 배터리는 10% 단위로만 제공됩니다(에어팟 자체 신호의 특성).
- 신호 포맷은 역분석된 것이라 일부 기종/펌웨어에서는 오프셋을
  조정해야 할 수 있습니다. 수치가 이상하면 알려주세요.
